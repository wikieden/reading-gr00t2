新增或修改一个动画

  1. 页面引用 anim.css 和 anim.js（与 vla-deep-dive、robot-system-architecture 同一套），提供 reset(seed) 和 next()（返回 false 表示播完），用 setupPlayer({captureSeed, reset, next}, 毫秒) 挂上播放按钮。随机数用 rnd() / gauss()。注意别再声明 anim.js 里已有的全局名（如 NS）。
  2. 重新录 GIF（在本目录下执行）：

bash node ../../../tools/anim-capture/capture.mjs 06-cps-grpo.html 06-cps-grpo.gif 900

  1. 讲义"讲解"末尾的 ### 动画演示 引用 GIF，然后跑 python3 tools/gallery/build.py 和 tools/notes-sync/sync.sh gr00t2 "GR00T 2"。
