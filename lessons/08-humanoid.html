本章缩写：S0 / S1 / S2 = System 0 / 1 / 2（底层控制器 / 快策略 / 慢推理）；PD = Proportional-Derivative（比例 / 微分）控制；DP = Diffusion Policy（扩散 / 策略）；OOD = Out-of-Distribution（分布 / 之外）；CMA-ES = Covariance Matrix Adaptation Evolution Strategy（协方差矩阵 / 自适应 / 进化 / 策略）。全部缩写见 附录 · 缩写与术语表

讲解

第一步：三层栈，每层一个频率（2026-11-15）

类比：骑自行车。 你决定"去超市"（S2，偶尔想一次）；你规划"接下来一两秒往左拐、捏刹车"（S1，约一秒一次）；身体自动保持平衡、蹬踏板（S0，每秒几十次，不用想）；肌肉纤维收缩（PD，更快）。

层 谁 输入 输出 频率 跑在哪
S2（可选） 推理模型 / 脚本任务计划 / 操作员 任务 选任务、在图上标物体或放置点，监控、失败重规划 按需 —
S1 GR00T 2 Turbo 头 + 双腕 RGB、关节位置（50 Hz 本体感知）、语言 1.6 s 动作块 = 80 个 SONIC 全身运动 latent token + 夹爪宽度 约 1 Hz 重规划 Jetson AGX Thor（机载）
S0 SONIC 全身控制器 当前 latent token + 本体感知 关节位置目标 50 Hz Jetson Orin NX（机载）
硬件 关节 PD 关节目标 力矩 1000 Hz 电机驱动

出处：Fig. 9（L783–L827）、附录 H.1（L6614–L6625）。

例子：80 是怎么来的。 动作块 1.6 s，S0 每 20 ms（50 Hz）取一个 token：\(1.6\ \text{s}\times50\ \text{Hz}=80\) 个 token。每 1 s 重规划一次，所以相邻两块有 \(1.6-1.0=0.6\) s 重叠，留出推理时间（Jetson Thor 上 124 ms）。

为什么用 latent token 当动作空间（H.1）：同一个 token 空间贯穿数据采集、仿真和部署——遥操作时操作员的动作先编码成 token 再由 SONIC 执行，所以演示直接录在策略的动作空间里；仿真里也跑同一个 SONIC。夹爪宽度不经 SONIC。

一句话：Turbo 一秒想一次"接下来 1.6 秒的全身动作"（80 个 token），SONIC 每 20 ms 把一个 token 变成关节目标并负责平衡。

第二步：真机结果（2026-11-15）

类比：同样的教材、同样的教练，换学生比成绩。 所有方法用同一批演示后训练、同一个 SONIC 当 S0，只换 S1。

例子：Tab. 25（成功率 %，无部分分）：

任务 次数 DP（latent token 上的扩散策略） π0.5 GR00T 1.7 GR00T 2 Turbo
爆米花舀取与递送（一手拿杯、一手舀，每次要两满杯） 48 27.1 0.0 83.3 100.0
桌面清理（每次 6 件杂物，走到垃圾桶放进去） 30 0.0 0.0 73.3 93.3
地面拾取（弯腰捡 30 种物体） 30 36.7 30.0 50.0 83.3
全身清洁（拿毛巾、捡杯子、用脚擦地、丢掉） 30 10.0 0.0 43.3 46.7
平均 18.5 7.5 62.5 80.8

爆米花还更快：两杯约 41 s，GR00T 1.7 约 48 s（L6750 附近）。桌面清理的失败多是餐巾、薯片袋这类扁平物体夹不起来。

一句话：同数据同控制器，换成 WAM 的 Turbo 当 S1，平均成功率 62.5% → 80.8%；最难的"用脚擦地"仍不到一半。

第三步：动作不变、换场景——以运动为中心的仿真扩增（2026-11-15）

类比：同一段舞蹈，换一百个舞台录。 遥操作录下来的全身动作是宝贵的，别浪费：保持动作不变，去仿真里找"让这段动作恰好能完成任务"的桌子和物体摆放，再在很多房间里渲染。

流程（附录 H.3，Fig. 59）： 1. 取一条遥操作 episode 的全身动作（只要动作）； 2. 在 MuJoCo / Isaac Lab 里用同一个 SONIC 回放，CMA-ES 搜索场景：先拟合桌子位置、高度、偏航角，再拟合物体类型、位置、朝向；每代并行评估 48 个候选； 3. 物理校验：只保留"双指抓住、提起、并在 30 帧、等于物体重量的扰动力下拿稳"的拟合； 4. 同一个通过的拟合，在大量生成的房间里渲染成合成演示。

例子：Tab. 26（G1 桌面抓放，30 次，同一份真实数据里混入仿真演示）：

策略 分布内：真 真 + 仿 分布外：真 真 + 仿
π0.5（VLA） 40.0 16.7 0.0 13.3
GR00T 1.7（VLA） 46.7 66.7 6.7 40.0
GR00T 2 Turbo（WAM） 73.3 83.3 6.7 63.3

分布外起点都是 6.7%（30 次里 2 次），加仿真后 WAM 涨到 63.3%（19 次），VLA 到 40.0%（12 次）。π0.5 在分布内加仿真反而掉了。作者的结论标题就是 "WAMs Consume Simulation Data Better than VLAs"（L6765）——一个合理的解释是：仿真画面和真实画面有差距，WAM 本来就在学"画面怎么变"，更能把仿真里的视觉多样性当成有用的监督；这一点白皮书没有做因果消融。

一句话：保持真实动作和控制器不变、只在仿真里换场景，WAM 把分布外成功率从 6.7% 拉到 63.3%，比 VLA 吃得更好。

数学原理

  • 多速率控制：慢层输出被快层按时间插值/逐格消费；慢层周期 < 动作块时长，才能无缝衔接。
  • CMA-ES：无梯度的进化优化，按协方差矩阵自适应地采样候选，适合"回放成功 / 失败"这种不可微目标。

公式清单

公式 意思
token 数 = 块时长 × S0 频率 = 1.6 × 50 = 80 动作块长度
重叠 = 块时长 − 重规划周期 留给推理的余量
